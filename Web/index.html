Polish Cyclometer Simulator

Overview

The Polish Cyclometer was created in Poland to help decode the German's enigma machines during WWI. It was also pivotal in creating Turing's Bombe in England.

Unfortunately, there are relatively few resources online for this machine compared to the enigma machine. I wasn't able to find a simulator online, so I made this one myself. This website (currently) doesn't explain how the Polish Cyclometer helped with decryption, so please use the linked resources below for more information.
